# Crédits

## Assets

Aucun asset graphique ou sonore externe à ce stade : tous les modèles low-poly sont générés
par le code (`scripts/visuals/lowpoly.gd`). Toute ressource externe ajoutée sera sous licence
CC0 et listée ici avec sa provenance.
